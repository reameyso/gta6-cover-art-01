Vice Sunset turns any photo and a caption into multi-panel GTA 6-style cover art — a hero panel plus two side panels with diagonal gutters, a warm sunset grade, and bold outlined lettering — and exports it as a PNG in 1080x1080, 1080x1350 or 1920x1080, fully offline in the browser. Your photos never leave your machine.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080, load up to three photos (or one photo for all panels), drag to crop and position each panel, edit the caption, pick an export size and hit Export PNG.
